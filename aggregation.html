How a broker plugs in

A broker sends inventory as a simple feed (or we ingest their existing export). Each lot is normalized into one schema, industry-tagged, and published with SDS/COA — pricing stays private and is handled per-RFQ.

POST /api/ingest
{
  "broker": "altiras",
  "lots": [
    { "name": "Isopropyl Alcohol 99.9%", "cat": "solvents",
      "cas": "67-63-0", "qty": "18 drums (208L)", "pkg": "Drums",
      "condition": "Overstock", "docs": ["SDS","COA"],
      "industries": ["cleaning","coatings","pharma"] }
  ]
}

Locally the same data lives in data/broker-feeds.json and is aggregated by build-catalog.ps1 into the live catalog.
